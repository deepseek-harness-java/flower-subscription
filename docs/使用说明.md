# AI 鲜花订阅管家 · 使用说明

## 一、系统简介

本系统由两部分组成：

- **鲜花订阅业务台**（p-app，端口 18105）：浏览器打开的看板页面，含运营看板、订阅实况、本期配送三个卡片，以及右侧 AI 管家对话窗（粉紫主题）。
- **AI 管家（flower-copilot）**：通过 DSH Java Native Plugin 注册进 Harness 的智能体，可调用 6 个业务工具，用自然语言完成咨询与订阅。

## 二、启动步骤

1. 启动 DSH Harness（8090，standalone）并配置模型。
2. 安装并激活插件 `flower-copilot`（见 README 快速开始）。
3. 启动业务应用：`java -Dserver.port=18105 -jar p-app/target/p-app-1.0.0-SNAPSHOT.jar`。
4. 浏览器访问 `http://127.0.0.1:18105`。

## 三、能做什么（含示例话术）

### 1. 套餐查询（plan_list）
> "有哪些订阅套餐？帮我妈选一个适合家居摆放的"

4 档套餐：轻氧周刊 ¥99 / 缤纷双周 ¥168 / 浪漫周享 ¥228 / 尊享定制 ¥399；管家会按场景（自用/送礼/家居）给推荐理由。

### 2. 花材养护（flower_care）
> "玫瑰的花语是什么？怎么养？"

在售花材：玫瑰、向日葵、郁金香、洋桔梗、尤加利叶；返回花语与养护技巧（剪根/水位/换水频率）。

### 3. 新建订阅（subscribe）
> "我是林芳，手机13987654321，订 P03 浪漫周享，地址徐汇区樱花大道88弄3-201"

规则：
- 下单前管家会**复述套餐/价格/频次/地址**请你确认；
- 套餐编号错误会被拦截并提示可选项；
- 成功后返回**订阅编号**（S5001 格式）与**首束配送时间**。

### 4. 订阅查询（sub_info）
> "查一下订阅 S5004"

返回套餐、配送地址、配送时段、下次配送时间、状态与历史配送记录。

### 5. 配送列表（deliveries）
> "这周配送安排怎么样？每单都送什么花？"

返回每单花束内容、收花人、时段与状态（待配送/配送中/已送达）。

### 6. 运营看板（stats）
> "订阅业务这个月运营得怎么样？"

返回生效/暂停订阅数、总订阅人数、**月流水 MRR**、分套餐分布、待配送数与运营建议（升级活动、暂停回访、备货提醒）。

## 四、安全与边界

- 花语与养护**只转述工具返回**，不编造花材库存与功效；
- 订阅涉及付费，必须先复述要素并获客户确认；
- 推荐套餐结合场景，不夸大宣传。

## 五、常见问题

**Q：提示"正在执行上一条消息"？**
上一个请求还在处理。可等几秒，或调用 `POST /api/agent/flower-copilot/cancel` 后重试。

**Q：套餐编号报错？**
仅支持 P01–P04，可先让管家列出套餐再选。

**Q：插件激活失败 / 调用了旧工具？**
先卸载再重装：`POST /api/harness/plugins/flower-copilot/uninstall`，重新 install + activate，并重启 DSH 以清空会话缓存。
